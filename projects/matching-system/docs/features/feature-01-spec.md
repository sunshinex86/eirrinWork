# Feature Spec: マッチング品質向上 + スキルタグ標準化

> Feature ID: 01
> Status: **Implemented** ✅

## Raw Requirement 要約
キーワードマッチングの限界を克服するため、スキル深度・プロジェクト文脈・ロールの3観点を追加したマッチング品質向上と、スキル辞書・同義語統一・スキルツリー構造によるスキルタグ標準化を実現する。

## 機能一覧

### Phase 1: マッチング品質向上
| 機能 | 説明 |
|------|------|
| ルール＋埋め込みスコア関数 | 既存5軸を維持しつつ、ベクトル埋め込みによる意味的マッチングを追加 |
| スキル深度 | 経験年数ベースのスコアリング（比率に応じた4段階評価） |
| プロジェクト文脈 | 業界タグ＋業務内容の埋め込み類似度による文脈マッチング |
| ロールモデリング | 6ロール（SE/PM/アーキテクト/DS/デザイナー/インフラ）の分類と一致スコア |

### Phase 2: スキルタグ標準化 + RAG/MCP/SKILLS
| 機能 | 説明 |
|------|------|
| スキル辞書 | 136エントリ、13カテゴリ、同義語情報付き |
| スキルツリー | 5ルートカテゴリ、最大5階層（115ノード） |
| 同義語正規化 | 150+エントリのシノニムマッピング |
| 標準化プログラム | 辞書＋同義語＋正規化の3段階標準化 |
| RAG パイプライン | キーワード・埋め込みによるナレッジ検索 |
| MCP ツール | 4ツール（matching_score/search_skills/get_skill_context/search_knowledge） |
| AIエージェントスキル | 4スキル（skill_gap/industry_context/improvement/rank） |

## 非機能要件
- 既存システムへの影響ゼロ（独立モジュール）
- グレースフルデグラデーション（依存ライブラリ未インストール時も動作）
- 全テスト PASS（既存119テスト含む388テスト）
- カバレッジ 80% 以上（実績86%）
