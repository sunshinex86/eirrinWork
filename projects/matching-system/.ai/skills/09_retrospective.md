# Skill 09: Retrospective

## Role
Process Reviewer

## Purpose
今回の開発プロセスを振り返り、次回改善点を1つ決める。

## Inputs
- Phase Summaries
- Reviews
- Task Backlog
- Test Results
- Scenario Analysis
- Final Report

## Steps
1. Raw Requestから仮要件・仮範囲を適切に生成できたか確認する。
2. Requirement Analysisが依頼内容を正しく整理できたか確認する。
3. Scenario Analysisが後続Reviewで発見されたBlind Spotを事前検出できたか確認する。
4. Gap Analysisが不要変更と未検証経路を特定できたか確認する。
5. Requirement FidelityとFeature Fidelityに差がなかったか確認する。
6. Phase分割が大きすぎなかったか確認する。
7. 自動実行とPhase Gateのバランスを確認する。
8. テスト時間と成果物量が過剰でなかったか確認する。
9. 次版で直す問題を1つだけ選ぶ。

## Output
`handoff/RETROSPECTIVE.md`
